Quiver

The verifiable risk brain for AI agents. Twenty-two priced computations an autonomous agent calls over HTTP and pays for in-band. No chat, no human in the loop.

An agent should not have to trust a number it just bought. Every deterministic answer here ships the inputs it used, the engine's build identity, a self-check against the condition the answer was solved from, and a signed content hash — so the caller re-derives the result instead of believing it. Live-market reads cannot promise a re-run and say so, in a different envelope. The distinction is enforced in code.

Check that in ten seconds, without paying or asking us

curl -s https://quiver-production-c3a8.up.railway.app/build

Returns the engine's build hash and the exact rule that produced it — the file list, the ordering, the digest. Clone the repository, follow that rule, and you get the same string. It is a SHA-256 over source bytes, so it reproduces outside JavaScript entirely.

curl -s -X POST https://quiver-production-c3a8.up.railway.app/api/perp-gate \
